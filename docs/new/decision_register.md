# Decision Register

The running ledger of architectural decisions. This is the canonical
answer to "did we already decide this?" and the only place where a
decision's status changes over time.

- **Aging policy:** any `Proposed` decision older than 90 days fails
  `tools/check_decision_register.py` in CI. Promote to `Accepted`,
  `Deferred`, or `Rejected`, or extend the deadline with a recorded reason.
- **Status values:** `Proposed | Accepted | Deferred | Rejected | Superseded`.
- **Supersedes:** a decision may supersede a prior decision by ID. The
  superseded decision is moved to `Superseded` and a `Supersedes: DEC-NNN`
  line is added.

## Schema

| Column | Meaning |
| --- | --- |
| `ID` | `DEC-NNN` (zero-padded, monotonic). |
| `Decision` | Short human title. |
| `Status` | One of the values above. |
| `Owner` | Role or name responsible for the decision. |
| `Date` | YYYY-MM-DD of the status set here. |
| `RFC` | Owning RFC number(s). |
| `ADR` | Backfilled ADR number, or `—` if none. |
| `Implemented?` | Yes / No / Partial. |
| `Notes` | Free-form context, links, or rationale. |
