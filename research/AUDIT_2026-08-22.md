## 2. Findings

### MEDIUM-1 — `.env.example` documents Settings but not the operational env surface — **FIXED**
`.env.example` (23 entries) covers every `core/config.py` Settings field and the
CALIENNE_-prefixed provider keys, but these consumed-in-code variables are absent:

- All 13 feature flags read by `orchestrator/feature_flags.py`:
  `CALIENNE_ENABLE_{DAG,CONSENSUS,CONTEXT,EXPERIENCE_DB,KNOWLEDGE_LAYER,
  META_ESCALATION,PLANNER,PREDICTION,RAG,REPAIR,REPLAY,SELF_LEARNING,SKILLS}`
- `CALIENNE_CAPABILITIES_PATH`, `CALIENNE_PROMPT_VERSIONS_PATH`,
  `CALIENNE_REPLAY_RETENTION_DAYS`, `CALIENNE_RETRIEVAL_WEIGHTS_JSON`,
  `CALIENNE_RETRIEVAL_WEIGHTS_PATH`, `CALIENNE_KEYRING_SERVICE`,
  `CALIENNE_GIT_COMMIT`, `CUSTOM_GATEWAY_KEY`

Impact: a new contributor (or the owner in three months) cannot discover the
flag surface from the example file. Fix applied: `.env.example` gained a
feature-flags section (all 13 gates, default OFF, env > feature_flags.json >
off precedence, v2-reserved flags called out) and an operational-tuning
section (keyring service, capabilities/prompt-versions path overrides, replay
retention — RFC-004 §6.3 default 30 days, retrieval weight JSON/path,
git-commit stamp, custom gateway key read order). All entries commented out;
copying the file enables nothing.

### LOW-1 — McNemar exact test overflows at n ≥ 1024 discordant pairs — **FIXED**
`evals/mcnemar.py:40` — `2.0**n` raises `OverflowError` when the discordant count
reaches 1024 (probed directly; n=1023 returns 2.23e-308, n=1024 crashes).
Unreachable at golden n=50, but it is a public API. Fix applied: integer shift
`sum(...) / (1 << n)`; regression tests at n=1023/1024/2000 (note: at n=2000
the true p ≈ 1e-602 underflows to 0.0, an acceptable lower bound).

### LOW-2 — Firewall substring bypass is vacuously true for empty claim content — **FIXED**
`orchestrator/claims.py:309` — `"".lower() in record.content.lower()` is always
True, so a degenerate empty claim would take the substring path to VERIFIED
(coverage gate is bypassed by design on substring matches). Upstream claim
extraction never produces empty content today, so this is defense-in-depth only.
Fix applied: the bypass now requires `len(claim.strip()) >= 4`. G3 frozen corpus
re-verified green (all 66 rows unaffected — corpus claims are full sentences).

### LOW-3 — `/metrics` bearer comparison raises on non-ASCII input — **FIXED**
`server.py` prometheus endpoint uses `secrets.compare_digest(presented, expected)`
on `str`; a non-ASCII `Authorization: bearer ñ…` header raises TypeError → 500
instead of a clean 401. Fix applied: both sides encoded to UTF-8 bytes before
comparing; regression param added to the bad-credentials test matrix.

### LOW-4 — `GET /api/config/vault` is user-gated, not admin-gated — **FIXED**
Any authenticated user sees the masked key status (configured-bool + last 4
chars) of server-level provider keys. The write path (`POST`) is correctly
admin-only. Last-4 masking is industry standard, so exposure is mild — but
consider `require_role("admin")` on the read for symmetry. Fix applied: read
gated to admin; frontend's ModelApiStudioModal already degrades gracefully
(`if (res.ok)` — non-admins see an empty vault list); docs/api.md regenerated;
route-dependency regression tests added.

## 3. Security surface — verified clean

- **Auth coverage**: every `/api/*` route carries `Depends(get_current_user)` or
  `Depends(require_role("admin"))`; admin-only correctly applied to models
  add/toggle, strategy mode, vault write, custom models, debug replay, provider
  health/recovery. Public routes are exactly `/login`, the hero video,
  `/auth/register`, `/auth/login`, `/auth/logout` (register and login are
  rate-limited). `/metrics` is fail-closed in production without
  `CALIENNE_METRICS_TOKEN` (see LOW-3 for the TypeError nit).
- **Cookies**: httpOnly, SameSite=strict, Secure outside development, max_age
  tied to JWT expiry (`_set_auth_cookie`).
- **CORS**: explicit allowlist only — `*` is rejected at startup; empty list is
  rejected (CRIT-004 posture intact).
- **SQL**: every statement in `orchestrator/memory_search.py` uses bound
  parameters (`:query`, `:owner_email`, `:since`, `:k`); `websearch_to_tsquery`
  receives the bind, never interpolated text. No string-built SQL anywhere else
  in the reviewed surface.
- **Tenancy**: both memory statements JOIN `conversation_sessions` and filter
  `owner_email`; provider returns `[]` when owner is missing (fail-closed);
  `user_id=current_user.email` threads server → `execute()` → `run_micro_mode`
  → memory/graph with `owner = user_id or ""` (empty owner matches nothing).
  `DELETE /api/conversations` purges only `owner_email == current_user.email`
  and rides the FK CASCADE.
- **Prompt containment**: judge prompt delimits query, both answers, and
  lessons via `_delimit_safe` — including the failure-pattern explanations
  interpolated at `pipelines.py:562`, which flow into `lessons` and are
  delimited downstream. Escaping re-verified (json.dumps + `<`/`>`/`&` →
  `\u003c`/`\u003e`/`\u0026`).
- **Secrets**: no hardcoded credentials in tracked files (scan hits were
  documentation prefixes and the base64 hero video); `.env` untracked; vault
  endpoint returns masked status only; `execution_replay` redacts bearer/JWT/
  API-key shapes before persistence.
- **Outbound HTTP**: httpx with default certificate verification, bounded
  600s timeout, no `verify=False` anywhere.
